#**📸 QuickSnip - Screenshot Tool for Windows 10**/n
[RU] Простая и быстрая утилита для создания скриншотов, которая имитирует поведение Windows 11 на старых версиях системы, добавляя автоматическое сохранение и удобное редактирование./n
**✨ Features / Возможности**/n
  Global Hotkey: Work by pressing Print Screen (or your custom key) even when minimized./n
  Auto-Save: Automatically saves images to Pictures/Screenshots folder./n
  Clipboard Support: Copies the screenshot to your clipboard instantly for quick sharing (Ctrl+V)./n
  Auto-Edit: Automatically opens the screenshot in the Windows "Snip & Sketch" editor.\n
  Settings Menu: Change the hotkey, save path, and toggle auto-start with Windows.\n
  Tray Mode: Runs quietly in the background without cluttering your taskbar.\n
**🚀 How to use**\n
  Download the latest version from the Releases section.\n
  Run Win11.exe.
  The app will appear in the system tray (near the clock).
  Press your hotkey to take a shot!
  Right-click the tray icon to open Settings or Exit.
**🛠 Tech Stack**
  Language: C#
  Framework: .NET Framework / WinFormsAPI: Win32 
  API (user32.dll) for global hotkeys.
**⚙️ Configuration**
  The app creates a config.txt file in its directory to store your custom hotkey code.
  Default Key: Print Screen
  Path: %USERPROFILE%\Pictures\Screenshots
